# Java

Простая и удобная Java-библиотека для взаимодействия с **[api.megoru.ru](https://api.megoru.ru)**.

---

## 📖 Документация

Подробное описание методов и примеры использования находятся в [GitHub репозитории](https://github.com/megoRU/api.megoru.ru-wrapper).

## 📦 Установка

> Добавьте библиотеку в зависимости проекта.

```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependency>
    <groupId>com.github.megoRU</groupId>
    <artifactId>api.megoru.ru-wrapper</artifactId>
    <version>5.1.4</version>
</dependency>
```

## 💡 Пример

```java
MegoruAPI api = new MegoruAPI.Builder().build();

var result = api.getWord(gameWordLanguage);

System.out.println(result.word());
```
