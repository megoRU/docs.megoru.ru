# Deleter — удаление текста по промпту {#deleter}

:::info Base API URL
`https://api.megoru.ru`
:::

## Конечная точка

| Метод | Endpoint       | Описание                                          |
| ----- | -------------- | ------------------------------------------------- |
| POST  | `/api/deleter` | Удаляет из текста содержимое по заданному промпту |

---

## Тело запроса (Request Body)

| Параметр | Тип    | Обязательно | Описание                                               |
| -------- | ------ | ----------- | ------------------------------------------------------ |
| `text`   | String | Да          | Текст для обработки                                    |
| `prompt` | String | Да          | Промпт с инструкцией по удалению содержимого из текста |

### Пример запроса

```json
{
  "text": "Американец смотрит Советские мультикм 😂#россия #kennethonline #смешно #юмор #чёрный",
  "prompt": "Удали хештеги"
}
```

---

## Заголовки

| Имя            | Тип    | Описание           |
| -------------- | ------ | ------------------ |
| `Content-Type` | String | `application/json` |

---

## Ответ сервера

### 200 OK — Текст успешно обработан

| Поле     | Тип    | Описание                                   |
| -------- | ------ | ------------------------------------------ |
| `result` | String | Текст после обработки по заданному промпту |

#### Пример ответа

```json
{
  "result": "Американец смотрит Советские мультикм 😂"
}
```

---

## Ошибки

### 400 Bad Request

Некорректное тело запроса.

```json
{
  "error": "Field 'text' and 'prompt' is required"
}
```

### 500 Internal Server Error

Внутренняя ошибка сервера.

```json
{
  "error": "Internal server error"
}
```
